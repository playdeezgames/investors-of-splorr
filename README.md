# Investors of SPLORR!!

**Made with AI.** A turn-based dungeon of seven rooms where a shopkeeper frames every charge as an opportunity. Made for [1-Bit Jam 15](https://itch.io/jam/1-bit-jam-15) ("Everything Has a Price") by TheGrumpyGameDev and Claude Code. Odin compiled to WebAssembly, drawn on a 2D canvas in two colours.

Play: https://playdeezgames.github.io/investors-of-splorr/ (latest) · https://thegrumpygamedev.itch.io/investors-of-splorr (itch.io)
